여러 원본 준비
1. 원본 지정


입력 계획 저장과 job 생성은 별도입니다. 이 생성 단계는 전사·대조·검수·승인·출력을 수행하지 않습니다. 후속 상태는 job에서 확인합니다. legacy v1은 참조만 하며 자동 전환하지 않습니다.






원본·조건·순서와 포함/제외 편집

형식을 명시적으로 선택하세요. 문제·해설·대본·정답·구조/영역 파일을 하나의 입력 단위로 추가합니다. 원본 내용 정확성과 관련 파일 관계는 자동 승인되지 않습니다.














중단은 현재 입력의 저장·결과 기록 후 적용됩니다. 창을 닫아도 생성은 계속됩니다. 결과 불명확은 자동 재생성하지 않습니다.




실패·복구·종료





배치 대상·revision·제외 사유를 다시 확인하고 배치 계획을 저장한 뒤 별도로 실행합니다.


고정 계획·근거 해시·이전 시도





승인본 일괄 출력


작업 전체의 현재 승인본을 기존 exporter로 출력합니다. 항목 승인은 기존 검수 화면에서 진행합니다.


















창을 닫거나 연결이 끊겨도 서버 처리는 계속될 수 있습니다. 복구는 재출력하지 않습니다. 실패·미실행은 검토 후 새 계획을 만들고, 결과 불명확은 기존 파일을 보존하세요.
